# MiniCode

[English](README.md) | [简体中文](README.zh-CN.md) | 한국어 | [日本語](README.ja.md)

MiniCode는 오픈소스 코딩 에이전트입니다.

MiniCode는 AI 코딩을 더 효율적으로 만드는 데 집중합니다. 코딩 에이전트는 탐색과 실행 과정에서 토큰과 모델 호출의 상당 부분을 소모합니다. 파일을 읽고, 검색하고, 다시 읽고, 다시 시도하는 일이 코드를 한 줄도 바꾸기 전에 이미 벌어집니다.

MiniCode는 더 나은 컨텍스트 관리와 실행 전략을 탐구하여, 에이전트가 하지 않아도 될 일에 들이는 수고를 줄입니다.

이 프로젝트는 초기 실험 단계에 있으며, 설계는 계속 바뀔 예정입니다.
