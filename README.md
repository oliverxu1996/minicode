# MiniCode

English | [简体中文](README.zh-CN.md) | [한국어](README.ko.md) | [日本語](README.ja.md)

MiniCode is an open-source coding agent.

It focuses on making AI coding more efficient. A coding agent burns a large
share of its tokens and model calls on exploration and execution — reading
files, searching, re-reading, retrying — before it ever changes a line of code.

MiniCode explores better context management and execution strategies, so the
agent spends less effort on work that never needed to happen.

The project is early-stage and experimental. Expect the design to keep moving.
