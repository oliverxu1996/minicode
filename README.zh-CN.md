# MiniCode

[English](README.md) | 简体中文 | [한국어](README.ko.md) | [日本語](README.ja.md)

MiniCode 是一个开源的编码 Agent。

它专注于让 AI 编码更高效。编码 Agent 会把很大一部分 Token 和 Model Call 消耗在探索和执行上——读文件、搜索、反复重读、反复重试——而这一切都发生在它真正改动一行代码之前。

MiniCode 探索更好的 Context 管理和执行策略，让 Agent 少把精力花在本不必要的工作上。

项目仍处于早期实验阶段，设计还会持续演进。
