# MiniCode

[English](README.md) | 简体中文 | [한국어](README.ko.md) | [日本語](README.ja.md)

MiniCode 是一个开源的 AI 编程智能体，专注于让 AI 编程更加高效。

编程智能体在探索和执行上会消耗掉大量 Token 和模型调用——读文件、搜索、反复重读、反复重试——而这一切往往发生在它真正改动第一行代码之前。

MiniCode 在探索更好的上下文管理与执行策略，让智能体少把精力花在本来就不需要做的事情上。

项目仍处于早期实验阶段，设计还会不断调整。
