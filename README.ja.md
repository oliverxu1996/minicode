# MiniCode

[English](README.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md) | 日本語

MiniCode はオープンソースのコーディングエージェントです。

MiniCode は AI コーディングをより効率的にすることを目指しています。コーディングエージェントは、探索と実行の過程でトークンとモデル呼び出しの大部分を消費します。ファイルを読み、検索し、読み直し、やり直す——こうした作業は、コードを一行も書き換える前にすでに起きています。

MiniCode は、より良いコンテキスト管理と実行戦略を探ることで、本来必要のなかった作業にエージェントが費やす労力を減らします。

本プロジェクトは初期の実験段階にあり、設計は今後も変化し続けます。
